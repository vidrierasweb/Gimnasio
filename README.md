# Pulso Gym — Demo de sitio para gimnasio

Sitio web demostrativo desarrollado por **Vidrieras Web** para un gimnasio con distintas disciplinas, planes de membresía y consultas por WhatsApp.

## Características

- Diseño responsive para celulares, tablets y escritorio.
- Presentación de disciplinas y actividades.
- Sección de planes y precios de ejemplo.
- Formulario interactivo para preparar una consulta sobre una clase de prueba.
- Accesos a WhatsApp para consultas y reservas.
- Preguntas frecuentes, horarios y testimonios ilustrativos.
- Animaciones y elementos interactivos.

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Demo online

https://vidrierasweb.github.io/Gimnasio/

## Importante

Este proyecto es una demostración de diseño web. El nombre, los precios, los horarios, la dirección, los testimonios y demás datos son ilustrativos. Antes de usar el sitio en un gimnasio real, se deben reemplazar por información verificada y configurar el número de WhatsApp y los datos de contacto.
